# candy-3d

Soft clay / candy 3D: pastel pink-to-sky gradient, glossy candy spheres bobbing at the edges, chunky rounded
cards with an inner highlight, a thick lilac base and a soft drop shadow. Rounded Fredoka headline with a 3D lip.

- **Mood**: cute, friendly, tactile, "Duolingo meets Pixar"
- **Palette**: bg `#ffe4f2 → #dff0ff`, panel `#fffbfe`, ink `#2e2150`, violet `#7c4dff`, pink `#db2f86`, teal `#0a879b`, orange `#d4540c`
- **Fonts**: Fredoka 700 (titles), Nunito (body), DM Mono (labels, code)
- **Ambient motion**: candy spheres bob and tilt in two groups (4 s and 6 s, phase-shifted)
- **Best for**: consumer apps, onboarding, habits / wellness, education, friendly product tours
- **Pairs with**: `bento-grid`, `circular-flow`, `orbit-panel`, `linear-progression`, `venn-diagram`, `cluster-map`
- **Sound**: `music`
- **GIF**: pastel gradients band slightly; default `sierra2_4a` dither with `--gif-colors 256` looks clean. Only the spheres move, so GIFs stay small.
