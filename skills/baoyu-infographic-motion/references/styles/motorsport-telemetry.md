# motorsport-telemetry

F1 pit-wall telemetry on a black carbon-fibre weave. Wide italic sport headlines, racing-red livery tabs on
every card, sector-timing colours (purple, green, yellow) for items, and red and white speed streaks that sweep across the page.

- **Mood**: fast, aggressive, race-engineer precision
- **Palette**: bg `#0b0b0d`, panel `#141418`, ink `#f5f5f7`, racing red `#ff2a1a`, sector purple `#b97cff`, sector green `#1fe06a`, sector yellow `#ffd400`, cyan `#38c8ff`, orange `#ff8a1c`
- **Fonts**: Saira wide italic (titles), Titillium Web (body), Roboto Mono (labels, data)
- **Ambient motion**: horizontal speed streaks on `.mi-page::after` that move left in a seamless 1400 px loop (2 s)
- **Best for**: performance benchmarks, leaderboards, latency / speed comparisons, live metrics, race-style rankings
- **Pairs with**: `live-dashboard`, `card-pipeline`, `linear-progression`, `comparison-matrix`, `binary-comparison`, `bento-grid`
- **Sound**: `music`
- **GIF**: the carbon weave is a fine repeating texture; use dither or accept larger files. Streaks are thin and fast, so export GIF at 15 fps or more
