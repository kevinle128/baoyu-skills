# github-dark

A GitHub README rendered as a poster: Primer dark canvas, a `README.md` tab bar, a very large tight Inter headline
with one green word, a `//` comment subtitle with a caret, bordered cards that turn Primer blue when active, and
mono paths in link blue.

- **Mood**: open-source showcase, "look what people built", credible and current
- **Palette**: canvas `#0d1117`, tab bar `#010409`, card `#161b22`, border `#30363d`, active border `#2f81f7`, link blue `#58a6ff` (accent), green `#3fb950`, orange `#f0883e`, purple `#a371f7`, red `#f85149`, yellow `#d29922`, text `#e6edf3`, muted `#8b949e`
- **Fonts**: Inter (800 headline, 700 card titles, body), JetBrains Mono (paths, labels, terminal)
- **Ambient motion**: comment caret blinks (1 s); the active card's blue ring, the hub ring and the green status dot breathe together (3 s)
- **Best for**: "N projects built with X" lists, repo round-ups, release notes, contributor or plugin showcases
- **Pairs with**: `bento-grid`, `columns-to-hub`, `ranked-leaderboard`, `source-listing`, `file-tree-anatomy`, `doc-terminal`, `card-pipeline`, `tile-router`, `periodic-table`
- **Sound**: `soft`
- **GIF**: flat dark fills compress well. The headline is capped at 66 px (the source uses ~130 px), so keep it to about six words. Labels keep their written case; write them in sentence case
