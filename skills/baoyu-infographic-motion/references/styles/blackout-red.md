# blackout-red

Brutal black-and-signal-red poster style. Ultra-bold condensed Anton headlines, hard 0 px corners, red slash
marks in the margins, and a red scan bar that sweeps the page while the title accent glitches now and then.

- **Mood**: aggressive, urgent, "incident report / fight card"
- **Palette**: bg `#050505`, panel `#0d0d0d`, ink `#f5f5f2`, red `#ff2323`, red-orange `#ff6a3d`, amber `#ff9d00`, steel `#d8d8d3`
- **Fonts**: Anton (titles, stats), Archivo Narrow (body), JetBrains Mono (labels, code)
- **Ambient motion**: red scan bar runs top to bottom over faint scanlines (5 s loop); title `<em>` gets a short red offset glitch once per 3 s
- **Best for**: hard-hitting comparisons, security / incident post-mortems, "X vs Y" verdicts, bold launch numbers
- **Pairs with**: `binary-comparison`, `comparison-matrix`, `bento-grid`, `live-dashboard`, `funnel`, `card-pipeline`
- **Sound**: `music`
- **GIF**: mostly flat black and red; the scanline overlay adds fine stripes, so use `compression` rather than dither
