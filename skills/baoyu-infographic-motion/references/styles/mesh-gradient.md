# mesh-gradient

Modern SaaS hero: a soft animated mesh of violet, coral, amber, sky and blurple blobs behind white frosted
cards. Tight sentence-case headline, gradient key word, clean mono labels.

- **Mood**: polished, friendly, "Stripe / Linear landing page"
- **Palette**: bg `#f6f7fb`, glass `rgba(255,255,255,.8)`, ink `#0a2540`, blurple `#635bff`, teal `#0a8fb0`, rose `#e3346f`, mesh `#a960ee #ff5b8a #ffcb57 #90e0ff #635bff`
- **Fonts**: Inter Tight 800 (titles), Inter (body), JetBrains Mono (labels, code)
- **Ambient motion**: mesh layer slowly rotates, scales and drifts (12 s)
- **Best for**: SaaS / API launches, product metrics, pricing and feature explainers, investor updates
- **Pairs with**: `bento-grid`, `hub-pipeline`, `columns-to-hub`, `live-dashboard`, `funnel`, `card-pipeline`
- **Sound**: `soft`
- **GIF**: smooth colour fields are the worst case for GIF banding. Keep `--gif-colors 256` with the default `sierra2_4a` dither; prefer MP4 for feeds.
